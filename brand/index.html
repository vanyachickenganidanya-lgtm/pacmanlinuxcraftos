01 — For agents

Как сделать так, чтобы нейросеть поняла стиль

Картинка в Figma нейросети почти бесполезна. Ей нужен контракт: точные hex, роли («этот цвет только для CTA»), запреты и скелеты компонентов. Формат, который сейчас едят Cursor / Claude Code / Codex / v0 — это DESIGN.md в корне репо, как на styles.refero.design.

1. Файл-закон

DESIGN.md

YAML-токены сверху, проза снизу. Одна атмосфера-строка. У каждого цвета — работа, не просто имя. Лежит в корне — агент подхватывает сам.

2. Запреты важнее вкуса

Don't

Без списка Don't агент включит Inter, градиент и «AI purple». Запрет — самый дешёвый способ держать стиль.

3. Откуда брать мясо

Steal list

Разреши 21st.dev на скелеты (ASCII, terminal). Refero — на дисциплину (Linear / Monad). Запрети палитры и rainbow-кнопки.

В этом репо уже лежит вся цепочка: DESIGN.md → AGENTS.md → .cursor/rules/design.mdc → эта страница. Промпт агенту: «strictly follow DESIGN.md».

02 — DNA

Три столпа, не четыре

TTY truth

Это терминал.

Нет GUI, нет иконок-в-кружках, нет «feature grid» как у SaaS. Продуктовый кадр — окно GRUB / dmesg / pacman.

One flashlight

Один фосфор.

Как acid-lime у Linear на Refero: #C8F542 зажигает одно действие на экран. Остальное — тёплый монохром.

Editorial silence

Серриф шепчет.

Как Monad: заголовки Instrument Serif 400, весь UI — моно. Жирный шрифт запрещён. Контраст делает гарнитура.

03 — Color

Палитра с должностями

Клик копирует hex. Агенту нужны не «зелёный и чёрный», а роли. Phosphor — фонарик. Amber — предупреждение. Panic — смерть процесса. Cyan — dmesg info.

07 — Voice

Как man-page, не как лендинг

Do say

«Без GUI — только терминал.»
«install auto — установка и ребут в GRUB.»
«Если http недоступен — встроенный extra.»

Don't say

«Unlock your Linux potential.»
«Reimagine crafting.»
«Seamless next-gen OS experience.»

08 — Law

Это читает модель первым

Do

Делай

  • Instrument Serif 400 на заголовки, IBM Plex Mono на всё остальное
  • Один фосфорный CTA на экран
  • Границы 1px Rule, не тени
  • Сетка 4 / 8 / 16 / 24 / 96
  • Eyebrow 01 — NAME перед серриф-заголовком
  • Hero начинать с ASCII/terminal скелета
Don't

Не делай

  • Inter, Roboto, вес 600+
  • Градиенты на кнопках и заголовках
  • Пилюли-кнопки, rainbow, liquid metal
  • Чистое #000 / #fff холстом
  • Стив, крипер, клипарт-Тикс как лого
  • «AI purple» #8b5cf6 и второй цветной fill

10 — Agent prompt

Вставь это в Cursor / Claude

Плюс @DESIGN.md. Без файла промпт держится одну сессию. С файлом в корне — весь проект.

Open DESIGN.md 
Read DESIGN.md at the repo root and follow it strictly.

Visual contract:
- Canvas #080A09, surfaces #101412 / #171C19, hairline #2A332E
- Display: Instrument Serif 400. UI/body: IBM Plex Mono 400/500
- One phosphor CTA #C8F542 on #080A09 per view
- No weight 600+, no gradients on UI, no Inter, no rainbow, no liquid metal

If you need a component skeleton, take structure from 21st.dev
(ASCII hero, terminal window, dark compact cards) and restyle
every color/font/radius to DESIGN.md tokens.

If you need a taste reference, Linear + Monad on styles.refero.design
are the method, not the palette.
