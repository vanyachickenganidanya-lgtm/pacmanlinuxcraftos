# Agent bootstrap

Read [`DESIGN.md`](./DESIGN.md) before any UI.

Brand: **Shizuku running on a ComputerCraft monitor.**

- Pixel fonts only (Pixelify Sans / Monocraft / Unbounded). Sizes 12 / 16 / 24 / 32 / 48 / 64.
- Booleans = Material 3 switches 52×32, phosphor when ON, Android Settings / Shizuku rows.
- Icons 16×16 or 32×32, `image-rendering: pixelated`. Recreate Minecraft blocks. No Mojang jar files in git.
- Open source: credit, GPL/MIT/Apache. Internet assets need a source line.

No Inter, no serif, no iOS toggles, no rainbow, no liquid metal.

Steal list: AOSP Settings, Shizuku, Minecraft 16×16 language, 21st.dev ASCII/terminal skeletons, Refero DESIGN.md method (not palettes).
