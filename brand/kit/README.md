# Kit — твой стиль в любой репозиторий

Скопируй в **корень** другого проекта:

| этот файл | кладёшь как |
|-----------|-------------|
| `DESIGN.md` | `DESIGN.md` |
| `AGENTS.md` | `AGENTS.md` |
| `design.mdc` | `.cursor/rules/design.mdc` |
| `tokens.css` | `src/tokens.css` или `static/tokens.css` |

В `DESIGN.md` замени только шапку: `name`, `description`, абзац **This project**.

Промпт агенту: `Read DESIGN.md and follow it strictly.`

Стиль не меняется от проекта к проекту — меняется только продукт.
